Fedora Drive Sync

A personal file backup setup operated by the owner of the connected Google account. It uses rclone on a Fedora Linux computer to upload selected local folders to the owner's Google Drive.

Purpose and Google Drive access

Google Drive authorization allows this setup to inspect files and metadata, create backup folders, and upload or update files. If the owner enables mirror mode, it can also remove destination files that have been deleted locally.

Although the requested permission permits access throughout the authorized Drive, the backup commands are configured by the owner to operate on selected destination folders.

This setup is for the account owner's personal use. This public information website does not provide a login or access to any backup files.

Privacy policy

Operator and contact: the owner of the connected account, using the support email shown in this app's Google authorization settings.
